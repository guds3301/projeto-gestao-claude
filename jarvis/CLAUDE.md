# Cofre Jarvis (segundo cérebro)

Este cofre é uma pasta de notas Markdown do Obsidian. Ao trabalhar aqui:

## Estrutura
- `00 Inbox`: capturas rápidas, sem organizar. Processar com frequência.
- `10 Projetos`: coisas com objetivo e prazo.
- `20 Áreas`: responsabilidades contínuas (saúde, finanças, trabalho).
- `30 Recursos`: temas e referências.
- `40 Arquivo`: o que já terminou.
- `Diário`: uma nota por dia (`AAAA-MM-DD.md`).
- `Templates`: modelos de nota.

## Convenções
- Uma ideia por nota, título claro, escrita com as próprias palavras.
- Ligue notas relacionadas com `[[wikilinks]]`.
- Propriedades (frontmatter) em toda nota: `tipo`, `status`, `criado`.
- Não apague notas; mova para `40 Arquivo`.

## Como o Claude deve ajudar
- Processar o Inbox: sugerir título, pasta e links para cada nota.
- Resumir notas e encontrar conexões entre elas.
- Nunca reescrever o conteúdo original sem pedir confirmação.
