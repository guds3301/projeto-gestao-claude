# Jarvis: estrutura inicial do cofre

Copie o conteúdo desta pasta para dentro do seu cofre do Obsidian (a pasta do cofre, não a pasta `jarvis`).

No Obsidian:
1. Configurações → Core plugins: ative **Daily notes** (pasta `Diário`, template `Templates/Diário`) e **Templates** (pasta `Templates`).
2. Opcional: plugins comunitários Dataview, Templater, Calendar e Tasks.
